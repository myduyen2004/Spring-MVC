About

This is a simple blog application built with Spring Framework. The blog features:

  • User authentication
  • Post management (create, update, delete)
  • Comment system with moderation
  • Tag cloud
  • Recent comments listing

This blog was created as a demonstration of Spring Framework capabilities including:

  • Spring Core (IoC, DI)
  • Spring Data JPA
  • Spring MVC
  • Thymeleaf templating
